---

### 方法一：快捷键全局缩放（最推荐、即时生效）

Antigravity 客户端支持与浏览器/Electron 类似的全局等比例视图缩放：

- **放大 UI 与文字**：`Ctrl` + `+`（或 `Ctrl` + `=`）
- **缩小 UI 与文字**：`Ctrl` + `-`
- **重置为默认大小**：`Ctrl` + `0`

> **提示**：该快捷键会同时缩放侧边栏、对话气泡、输入框及代码视图，是解决界面字号偏大或偏小最直接的方式。

---

### 方法二：针对 Antigravity IDE（精确微调）

如果您使用的是基于 VS Code 架构的 Antigravity IDE，可分别单独设置代码、聊天或整体 UI：

1. 按 `Ctrl` + `,` 打开 **Settings（设置）**。
2. **调节编辑器字号**：搜索 `Editor: Font Size`，将数值调大（如 `15`、`16` 等）。
3. **调节终端字号**：搜索 `Terminal > Integrated: Font Size`。
4. **精确调整窗口缩放级别**：搜索 `Window: Zoom Level`，设置缩放增量（如 `0.5`、`1`、`1.5` 等）。

---

### 方法三：针对 Antigravity 桌面端（Antigravity 2.0）

1. 直接使用 **方法一** 的 `Ctrl` + `+` / `Ctrl` + `-` 快捷键缩放。
2. 点击左侧边栏底部的 **Settings**（齿轮图标），在 **Appearance** 中可调整对话区域宽度（Conversation Width）与界面主题。

---

### 方法四：高分屏（4K / 2K）DPI 适配

若在高分辨率显示器上整体偏小：
- 可右键桌面空白处 -> **显示设置** -> 将 **缩放与布局**（DPI）由 100% 调整为 125% 或 150%。

### 三、 支撑深度汉化的技术演进：作用域消歧（Scope-Aware）

随着词库的成倍扩充，单纯的全局字符串替换容易遇到**“一词多义”**的问题：
* 比如单词 **`View`**：
  * 在顶部菜单栏是 `视图`；
  * 在卡片操作按钮上是 `查看`；
  * 在代码比对区是 `预览`。
* 比如单词 **`Save`**：
  * 表单里是 `保存`；
  * 状态指示里可能是 `已保存`。

**解决方案：升级翻译引擎为“选择器与上下文感知引擎（Scope-Aware Engine）”**：

// 示例：按 DOM 作用域分类翻译，杜绝上下文混淆
const SCOPED_DICT = {
