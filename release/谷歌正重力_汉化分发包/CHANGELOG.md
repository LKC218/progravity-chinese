# 变更日志与版本规范 (CHANGELOG)

本项目遵循语义化版本规范进行演进，以 **`V2.0`** 作为统一的起点基线版本。

---

## [V2.1.1] - 2026-09-21
**作者**: @LKC218

### 🛠️ 体验修复与性能优化
1. **单一宿主收敛与残留彻底清扫**
   - 彻底剥离历史折叠面板（`worked-for-collapsible`）的不当挂载，金句仅限在运行态底部状态条（`agent-loading`）呈现；
   - 任务结束或进入正文输出时执行全域无死角清扫，保证历史消息记录纯净，彻底杜绝“结束后仍残留金句”问题。
2. **金句记忆锁 (Linger Lock) 与 8 秒黄金呼吸节奏**
   - 引入全局记忆锁机制，跨多工具连续调用时平稳保持相同金句，彻底消除因 React 频繁重建导致的 1~2 秒疯狂跳字；
   - 轮播步长精准放缓至 **8 秒**，短任务全过程单金句陪伴，长任务平缓更替；
   - 融入 400ms 平滑淡出与 2px 浮动微动效，极光流光自然过渡。
3. **全局生命周期管理防重注册**
   - 接入 `window.__antigravity_observer` 自动断开卸载机制，热重载时自动清理旧实例，杜绝多实例幽灵并发。

## [V2.1] - 2026-09-21
**作者**: @LKC218

### 🌟 核心新特性
1. **思考过程与动作步骤深度汉化**
   - 采用多维复合正则动态重组：如 `Explored X files, Y searches, ran Z commands` 地道汉化为 `已探索 X 个文件、Y 次搜索，运行了 Z 条命令`；
   - 动作谓词全面地道化：`Ran` $\rightarrow$ `已执行`、`Searched` $\rightarrow$ `已检索`、`Thought for` $\rightarrow$ `思考耗时`、`Working for` $\rightarrow$ `工作耗时` 等。
2. **状态条趣味幽默金句轮播池 (对标 WorkBuddy，随用随销定时器)**
   - 扩充至 **100 条** 极具极客趣味的幽默思考金句（涵盖硬核编程、科幻宇宙、职场打工、高情商真诚、拟人脑暴、玄幻修仙、探案破案、极速狂飙、游戏电竞、哲学美学等 10 大维度）；
   - 在思考/执行状态条动态呈现平滑淡入淡出（5秒步长随机轮播）；
   - 严格遵循**随用随销铁律**：一旦任务结束或进入正文输出，定时器与挂载元素立即彻底销毁，零后台残留。
3. **任务结束 Token / 算力额度消耗徽章 (对标 WorkBuddy ✧ 算力)**
   - 严格遵循**流式静默铁律**：模型在打字输出正文时统计引擎 100% 完全休眠，0 CPU 占用；
   - **事后一次性极速结算**：仅在生成彻底完成且操作栏就绪时单次计算（耗时 `< 0.1ms`），并打上防重标记锁定；
   - 底部操作栏左侧优雅挂载圆角胶囊徽章（如 `✧ 12.8`），鼠标悬停可查看 Token 组成与算力详细 breakdown。
4. **反重力品牌色动态流光渐变动效 (Aurora Shimmer)**
   - 金句字体呈现反重力品牌流光色彩循环（天青、星云紫、霓虹紫红、赛博青）；
   - 自适应 Dark / Light 双主题配色，全硬件 GPU 加速无卡顿渲染；
   - 联动自毁开关（Panic Switch），彻底卸载不残留。

## [V2.0] - 2026-09-20 (起点版本)
**作者**: @LKC218

### 🌟 核心新特性
1. **独立绿色 GUI 汉化助手 (单文件 EXE)**
   - 彻底摆脱对 Node.js、npm 和 Python 解释器的外部依赖；
   - 采用纯原生 Python 二进制流协议独立实现 ASAR 解包与封包引擎（解封包仅需 2 秒）；
   - 提供现代化卡片式桌面图形交互界面（Tkinter GUI）。
2. **零门槛分发机制**
   - 形成独立的 `release/谷歌正重力_汉化分发包`，任何普通用户解压后双击即可使用。
3. **词库外置协同维护**
   - 核心汉化字典完全外置为 `i18n.js`，任何人无需编译，用记事本即可随时扩展词条。
4. **一键安全机制与免重启热重载**
   - 自动生成官方原版备份（`app.asar.original.bak`），支持随时一键无损还原纯英文；
   - 支持通过 Chrome DevTools 协议（CDP）实现免重启客户端即时热刷新。
5. **品牌形象与个性化定制**
   - 定名“谷歌正重力”，并集成萌态破损趴地 A 专属高清图标。

## 📌 版本规范说明
- **主版本号 (Major)**：若 Antigravity 官方客户端底层架构发生大版本演进或注入机制发生重构时递增；
- **次版本号 (Minor)**：新增汉化功能模块、UI 助手功能迭代或重大词库扩充时递增；
- **修订版本号 (Patch)**：汉化词条纠偏、微小 Bug 修复或日常适配微调时递增。
